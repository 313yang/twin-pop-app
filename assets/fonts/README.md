# KccSign / KCC간판체

- 제작: 한국저작권위원회 (Korea Copyright Commission)
- 원본: https://cdn.jsdelivr.net/gh/projectnoonnu/noonfonts_2302@1.0/KCC-Ganpan.woff2
- 이용 안내: https://gongu.copyright.or.kr/gongu/bbs/B0000018/list.do?menuNo=200195&pageIndex=1&searchCnd=1&searchWrd=KCC
- 라이선스: SIL Open Font License, 동봉한 OFL.txt 참고.

사용자가 제공한 WOFF2를 fontTools로 압축 해제해 CFF 기반 OpenType(`KccSign.otf`)으로 저장했습니다. 글리프·글꼴 이름·저작권 메타데이터는 유지했습니다. Expo 런타임에서 `KccSign` 별칭으로 로드합니다. 네트워크 다운로드 없이 앱 번들에서 로드되며, 모든 앱 문구는 `AppText`를 통해 적용됩니다. Font Awesome 아이콘은 해당 아이콘 폰트를 유지합니다.
